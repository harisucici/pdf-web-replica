# スキャン再構築の品質基準

[中文](../../zh/references/scan-quality.md) | [English](../../../references/scan-quality.md) | [日本語](scan-quality.md)

毎回、原 PDF の座標に基づく選択可能な文字と、原本から切り出した図版を基準にします。OCR だけ、全行を同じゴシック体にする初稿には戻しません。詳細と形式は[英語の技術手順](../../../references/scan-quality.md)を参照してください。

- スキャン、とくに日中韓英の混在には隔離環境で `bootstrap.py --venv work/.pdf-web-env --enhanced-ocr` を実行し、返された Python を使用します。
- `build --ocr rapidocr --languages ja,zh,ko,en` は既定 216 dpi。`analyze` と `enhance --refine-ruby` で原本の領域と文字メトリックを合わせます。モデルは初回ダウンロード、文書処理はローカルです。他言語は対応した経路で処理します。
- 本文、ルビ、番号、縦書きラベルを分離し、明朝・ゴシック、太さ、基線と送りを実際の字形で比較します。ルビ込みの枠を本文サイズに使いません。
- 韓国語の別認識は同じ行・範囲だけと照合します。複数行が合体した高信頼候補で置き換えません。ルビは原本画素のみから読み、辞書で生成しません。
- 背景色、側欄、角丸、表の白いセル、番号の円、チェック枠と下線は独立した図形です。大きな文字の線をベクター図形に描き換えません。
- アイコン、キャラクター、矢印、ロゴ、図版は原 PDF から切り出します。`crop-artwork` は文字との重なりを拒否し、原本確認後のみ `--reviewed --note` で表示承認します。内部文字は `--exclude-text-bbox` で透明に抜き、見える Unicode と必要な背景を戻します。絵文字や生成画像で代用しません。
- 各版型の見本を直した後、対象全ページを原本と同じ寸法で比較します。表紙、説明、問題・解答、復習、付録を省略しません。差分後の修正は再撮影が必要です。

不明なフォントや読めない原本について無条件の完全一致は約束しません。具体的な修正を続けるか、未解決のページ・範囲と障害を記録します。表示成功だけで完成としたり、合格のために比較しきい値を緩めたりしません。

利用者が一部ページだけを指定した場合は `audit <output> --allow-range` を使います。全巻や未完の分割処理の省略を隠すためには使いません。
