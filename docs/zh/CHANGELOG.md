# 更新记录

## 1.1.0 — 2026-11-16

- 自动 OCR 在失败或无结果时尝试已安装的其他路线；批量输出保留 PDF 原名和相对目录。明确剩余原件差异会阻止验收。

- 开发 1.1.0 原件驱动的复刻迭代：区域分析、原件总览、逐页计划、排版补丁、纯页面截图就绪信号、像素差异图与版本绑定验收。新增 Pillow 依赖与合成证据回归检查。

- 恢复原阅读器界面，支持结构化原生 HTML/CSS 页面排版、全文搜索、文字侧栏与显式原页对照。

- 修复带留白或拼接扫描图被当插图的问题；网页仅显示经原件核对的独立插图，刷新迁移旧数据，补充提取和渲染回归检查。

- 完善 Hermes 客户端的 `/pdf-web-replica` 简短调用、附件和路径用法。
- 提供中文、英文、日文的 README、工作流程、技术参考和更新记录，并加入语言切换链接。
- 发布包包含三语文档；正式技能入口保留单个 `SKILL.md`。

## 1.0.0 — 2026-11-15

- 面向 Hermes Agent、Codex、OpenCode、OpenClaw 的可移植 Agent Skills 包。
- PDF 检查、原生文字/矢量提取、独立多语言 OCR 适配器和可选择的网页文字。
- 批量处理、续跑、显式重处理、加密文件、附件提取和逐页校验记录。
- 针对 Agent 不同 Python 环境的解释器分发器。
- 使用真实安装的 Hermes 验证技能发现、加载和 PDF 检查。
- 合成回归测试与浏览器检查；原件未完成校验时，生成文档保持草稿。

此版本不保证所有 PDF 的 OCR 完美无误或像素级一致重建。

- 增强本地 PP-OCR、字符坐标、原图字体/基线拟合、注音复查、原件图标裁切与透明文字排除；将这套质量流程设为每次调用的默认要求。修复特定尺寸原生图像库崩溃，加入 OCR 进程隔离与截图状态回归。
