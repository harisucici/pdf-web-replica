# 排版与 OCR 流程

[中文](layout-and-ocr.md) | [English](../../../references/layout-and-ocr.md) | [日本語](../../ja/references/layout-and-ocr.md)

## 先清点再排版

阅读每页记录。同一 PDF 可混合扫描、真实文字、已有不可见 OCR、矢量图、表格、表单、不同裁切和旋转。不能以第一页推断全书。CLI 尽可能保留原生矢量、真正的小插图与带坐标的 Unicode 文字，排除大幅整页复刻图。扫描页 OCR 后仍需原生布局重建。

默认 `site/` 没有源页截图背景。原始 PNG 放在独立的 `references/` 对照目录。真实大照片与带文字的扫描页不是同一类素材，加入 `images` 前应分类并隔离插图。不能把页面描成 SVG 后将文字轮廓称为独立网页文字。

## 原生几何

使用以点为单位、按显示裁切和旋转规范化的 PDF 坐标。原生文字包含基线起点、角度、字号和前进宽度。查看器显示真正的 Unicode SVG 文字而非轮廓或光栅画布，因此文字可以选择。若用户只接受 HTML 文字标签，可改成定位的 HTML span，保留基线和书写方向。

尽可能复用可在浏览器嵌入的原字体；CLI 会报告不能嵌入的字体。子集字体即便可嵌入也可能缺少 Unicode 映射，应先检查代表字形，再检查全部使用字符。替代字体不能宣称与原字体完全相同。粗体、斜体、下划线、基线、字距、注音、竖排和 RTL 均需校验。

原生路径是原始绘图元素，不是扫描文字描摹。裁切、混合模式、透明度、图案、Type 3 字体和特殊批注需要单独视觉检查。通用提取器生成初稿，并非完整 PDF 渲染引擎。

## 扫描与多语言

1. 以足够分辨率渲染代表页，肉眼识别全部文字体系。正式批量显式指定语言；`auto` 只是诊断首轮，不证明全部语言已识别。
2. macOS Vision 和 Tesseract 对指定语言分别识别，再做初步空间融合。检查冲突；类似汉字的结果可能是韩语误读，拉丁字母也可能是日文假名或变音符号误识别。
3. 其他后端可使用 `--ocr external --ocr-command-json '["python", "adapter.py", "{image}", "{output}", "{languages}"]'`。参数不经 shell。适配器将 `page-schema.md` 的 JSON 写入 `{output}` 或输出到标准输出。
4. 本地 OCR 都不可用时，使用宿主允许的视觉或文档工具。保留准确原文、语言、坐标并导入结果，不擅自用翻译、推测答案或词典注音填补缺失。
5. 彩色面板、分栏、单元格、线条、页标和装饰重建为独立形状，仅真正插图可作为图片资源。保留有意义的行和段落边界，不为塞进框而把整段压为一行。
6. 不确定文字可参考补充文字层或附录，但冲突以实际页面为准。补充文本也可能有错字或重复编号。

修改页面 JSON 后运行 `refresh <output>` 重新生成网页与文字。`--resume` 保留已处理和手工页面；需重新处理时用 `--resume --reprocess --pages <range>`，这会替换该范围并重置校验标记，先备份手工修正。

## 验收

真实浏览器中与同等比例的原件渲染对比，检查全部请求页面。测试首次加载、快速翻页、旋转页、真空白页、长页切短页、原文复制和搜索；若以本地方式交付，还应测试 `file://`。翻页归顶，加载失败不能伪装成原本空白。

只有证据充分才标记四项校验完成。OCR 置信度、页数、构建成功、好看的样例或单张截图都不能证明全书忠实。未解决问题保留在 `audit.json` 和交付说明中。

## 图片规则与旧输出迁移

不能用图片尺寸证明它是插图。带宽留白的 PDF 扫描图可能仅占画布 59%；多张小图也可能拼成整页。提取器结合裁切后位置、宽高跨度和矩形并集覆盖率识别这类图，在写入插图资源前排除。较小图片也只标为 `illustration_candidate`、`reviewed: false`，只有与原件对照确认是独立插图后才显示。查看器同样检查几何，包括仅有变换矩阵或多图拼接的情况。不能靠缩小 bbox 或设置确认标记恢复扫描底图。

对于真实独立插图，应查看资源与原页位置，必要时裁掉段落或整页内容，再在页面 JSON 设置 `role: "illustration"`、`reviewed: true`。触发保守扫描防护的大照片或图画，应明确分离或重建；防护不等于断言图片有文字。运行 `refresh <output>` 更新。审计不接受未经核对的候选图片。

更新旧输出而不重做 OCR、不覆盖手工文字时，从新版技能根目录执行：

```sh
python scripts/run.py refresh "/path/to/outputs/example"
```

刷新会迁移页面 JSON：疑似扫描图从 `images` 移到 `excluded_images` 元数据，其他未确认图片变为候选。变更页面的验收标记重置，文字、手工图形和备注保留。原图片文件不删除、不移动，不应继续作为插图发布；发布前检查交付资源目录。补齐缺失文字与排版并实际对照后，才记录验收。刷新会更新网页脚本和页面数据；线上旧副本仍需按用户授权的发布流程重新部署。
