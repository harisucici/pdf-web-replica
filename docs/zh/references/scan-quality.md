# 扫描件复刻质量基线

[中文](scan-quality.md) | [English](../../../references/scan-quality.md) | [日本語](../../ja/references/scan-quality.md)

每次调用都以「按原 PDF 坐标重建可选文字，图标从原件裁切」为默认目标，不能退回只做 OCR、统一黑体的初稿。完整参数和流程以 [英文技术说明](../../../references/scan-quality.md) 为准。

1. 扫描件，尤其日中韩英混排，使用隔离环境安装增强运行时：`python3 scripts/bootstrap.py --venv work/.pdf-web-env --enhanced-ocr`。后续使用返回的解释器。
2. `build --ocr rapidocr --languages ja,zh,ko,en` 默认 216 dpi，保留行/字符坐标与识别备选；随后 `analyze` 和 `enhance --refine-ruby`。PP-OCR 模型首次使用会下载，文档只在本地处理。其他语言选择适合的识别路线，不能省略。
3. 正文、小注音、题号、选项号和竖排标签分别定位。按原图墨迹、基线和实际字体度量拟合，比较明朝/衬线、黑体/无衬线及粗细，不能将含注音的大框直接当正文字号。
4. 韩语与中文、日文分段。交叉识别只能匹配同一行、同一范围，不能把合并了相邻两行的高分备选直接替换进正文。注音仅重新识别原图，不查词典补写。
5. 分别重建原色底板、窄侧栏、圆角/凹口、白色表格单元格、圆底题号、勾选框和下划线。不能把大号文字笔画当作线条或色块描摹。
6. 图标、吉祥物、箭头、标志和插画从 PDF 裁切，保留原位置和比例；不用 emoji、重画或 AI 生成图替代。`crop-artwork --page N --bbox x0 y0 x1 y1` 默认生成待核对候选；只有实际查看原件后才能加 `--reviewed --note "核对说明"`。正文相交会被拒绝。图画中的文字可用 `--exclude-text-bbox` 挖透明孔，再放回真实可选文字和必要底色。
7. 先修好每种版型样页，再覆盖全部页；每页截图与原 PDF 同尺寸比较，修正局部问题并重截图。封面大字、说明页、习题/解答页、复习与附录均不能跳过。

安装的模型、可用字体和原始扫描质量有差异，不能无条件承诺任意 PDF 的字体与像素完全一致。未达基线时继续修正或指出具体页/区域与阻塞原因，不能用「脚本跑完、网页能开」冒充完成，也不能降低验收阈值求通过。

用户明确只要求部分页面时，用 `audit <output> --allow-range`；全书请求和分批处理中途不能用此开关掩盖漏页。
